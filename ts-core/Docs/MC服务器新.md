### 🗺️ 核心架构总览
*   **网络链路**：玩家纯净客户端 ➔ 阿里云上海（FRP 端口映射/TCP 盲转发） ➔ 日本福冈 Windows 主机。
*   **废弃技术**：彻底抛弃 Velocity/BungeeCord（规避跨国断连 Bug），彻底抛弃 Paper 端（规避单线程性能瓶颈）。
*   **服务端核心**：**Fabric** 最新版（1.20+ 或 1.21+）。
*   **运行环境**：推荐使用 **Java 21**，并开启 ZGC 垃圾回收（启动参数加上 `-XX:+UseZGC -XX:+ZGenerational`），告别内存卡顿。

---

### 🛠️ 模组清单（全部放进服务端的 `mods` 文件夹）
**⚠️ 核心准则：所有模组均为纯服务端模组，玩家使用原版客户端直连，不需要安装任何整合包！**

#### 1. 极致优化套件（性能基石）
*   **Lithium（锂）**：全方位重写原版低效算法（AI、物理、碰撞），大幅降低 MSPT。
*   **C2ME**：利用 Windows 主机的多核 CPU 异步处理区块生成，保护主线程，跑图不卡。
*   **FerriteCore**：深度优化内存结构，显著降低内存占用和 GC 频率。
*   **Krypton（氪星）**：优化网络发包序列化，降低 CPU 占用，**极大改善跨国 FRP 链路的包处理延迟**。
*   *(可选扩展)* **ModernFix**：修复原版漏洞，进一步加快启动速度和优化内存。

#### 2. 多维度管理套件（代替群组服架构）
*   **Multiworld (Fabric) / Dimenager**：用于在同一个服务器内创建多个维度（主城维度、生存维度、资源维度）。
*   **Server Sided Portals**：跨维度物理传送门。在主城建几个传送门，玩家走进去“无缝丝滑”传送到生存/资源服，不掉线、无黑屏。

#### 3. 玩法与功能套件（代替传统插件）
*   **Holograms**：实现悬浮字全息显示，支持变量。
*   **Fabric Tailor** 或 **SkinRestorer (Fabric版)**：实现离线服正版皮肤显示或游戏内输入指令换肤。
*   **Flan**：领地与防破坏模组。用于保护主城不被破坏，同时允许玩家在生存服用金铲子圈地。

### ⚙️ 核心实操与运维规范（必做！）

#### 第一步：世界预生成（保命操作）
1.  安装 **Chunky** 模组。
2.  开服前，在控制台分别进入你的“生存维度”和“资源维度”。
3.  输入命令：`chunky radius 5000` ➔ `chunky start`。
4.  等待几个小时让 CPU 跑满，把这些区块全部在硬盘上生成好。（以后玩家跑图只会消耗极低的硬盘读取，CPU 毫无波澜）。

#### 第二步：配置优化文件
1.  修改 `server.properties`：
    *   `view-distance=10`（玩家视野，吃网速和内存）
    *   `simulation-distance=4` 或 `5`（模拟距离，**极其吃CPU**，调低能直接拯救服务器）
2.  设置主城保护：利用指令或 Flan 模组将主城维度的默认模式设为冒险模式或禁止破坏。

#### 第三步：日常运维（资源服重置）
*   **如何重置资源区？**：每月停服一次，直接在服务器存档文件夹中，把 `resource_world`（资源维度）的文件夹删掉。重启服务器后用 Multiworld 指令重新生成一个即可，玩家的背包、金钱、成就**完全不会受任何影响**（因为账号数据统一保存在主维度里）。

### 🌟 最终预期效果
1.  **网络极度稳定**：FRP 直接转发 TCP 到 Fabric，Minecraft 客户端的超强容错机制将完全接管网络波动，玩家哪怕卡一下也会自动恢复，**再也不会出现 Velocity 动不动就 Kick 玩家的恶心情况**。
2.  **性能暴打 Paper**：得益于 Lithium + C2ME，服务器的多核利用率大幅提升。同等硬件下，能承载的玩家数量和红石机器数量比以前提升 **1.5 倍以上**。
3.  **完美的跨服体验**：从主城走入生存服，就像进出下界一样丝滑，且**背包百分之百完美互通**，彻底消灭跨服同步数据库可能导致的丢号、刷物品等致命 Bug。



打造 Agent 女仆的 3 个“神级插件”推荐 (Node.js 端)
既然你要用 Mineflayer 做 Agent（大模型驱动或自动逻辑），有几个 NPM 库是你必须要配套使用的，它们能让你的女仆立刻“活”过来：
mineflayer-pathfinder (寻路核心)
作用：没有它，你的女仆就是个瞎子。加入它之后，只要给一个坐标（或者让你女仆跟着你），她会自动计算绕开岩浆、搭方块上山、跳过峡谷来到你身边。
mineflayer-pvp (战斗模块)
作用：当你被僵尸围攻时，你可以让 Agent 触发保护逻辑，女仆会自动走位、暴击、举盾帮你杀怪。
prismarine-viewer (上帝视角调试)
作用：在你的浏览器里开启一个网页，你可以实时看到你的女仆在游戏里看到的画面（第一人称 3D 视角）！这对你调试大模型 Agent 的空间感知能力极其有用。
